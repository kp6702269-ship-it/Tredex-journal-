Import / Export

Import a CSV file with columns: date, symbol, market, side, entry, exit, quantity, pnl, fees, notes. MT5 history exports (Time, Type, Volume, Price, Commission, Swap, Profit) are also understood. Commission and swap are treated as MT5 does: negative = charge. Already-imported rows are skipped. Always check the result before relying on totals.

MT5 connection

Direct MT5 account sync is not enabled in this prototype. A production integration needs a secure backend and a MetaTrader 5 Expert Advisor or broker-supported API to send closed-trade records.

Not connected

Demo mode saves data only in this browser. When signed in, trades are cached in this browser and also synced to your cloud account. Do not enter broker passwords, API secrets, or sensitive account credentials.

Import Trades

Upload a broker history screenshot (gallery or camera). OCR reads the text and prepares editable trade drafts. Several trades in one screenshot are supported.

OCR can make mistakes. Review every field before saving. Internet is required to load OCR. For best results, crop to the trade rows and use a bright, sharp image.
